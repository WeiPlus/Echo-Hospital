## About

Echo Hospital is a horror-themed dimension mod. Step through the portal and find yourself trapped inside an abandoned hospital filled with eerie corridors, unsettling encounters, and things that should not be there.

## Features

- A custom horror hospital dimension
- Portal to enter the Echo Hospital
- Eerie atmosphere with custom lighting and ambience
- Hostile entities roaming the halls
- Unique hospital-themed blocks and structures
- Progressive exploration with hidden rooms and secrets

## Requirements

- Minecraft 1.20.1
- Minecraft Forge (1.20.1)

## Installation

1. Install Minecraft Forge for 1.20.1.
2. Download the latest `.jar` file from the [Releases](https://github.com/WeiPlus/Echo-Hospital/releases) page.
3. Place the `.jar` file into your `.minecraft/mods` folder.
4. Launch Minecraft with the Forge profile and enter the dimension.
